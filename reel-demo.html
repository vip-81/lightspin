5×3 REEL CONTROLLER

滾輪滾動與停止控制器

純 JavaScript 邏輯層示範：所有 Reel 先加速捲動，收到後端矩陣後由左至右每隔 200ms 開始減速，停止時向下超調再向上回彈對齊。中獎結果完全由輸入矩陣決定，前端不計算中獎。

狀態機：Idle → SpinUp → LoopScroll → SpinDown → Bounce → ResultShow。
停止數學使用三次多項式，同時滿足起點速度連續、終點速度為 0、精確落在整數格；回彈使用 sin²(πt)·e^(-1.5t) 製造向下超調。每軸 phase 可不同步，以實現交錯停止。
