Why LightSpin

六大技術特色

以下是本示範採用的關鍵設計，每一項都可在行動裝置上驗證。

01

60 FPS 渲染管線

使用 requestAnimationFrame 搭配 delta time 更新，並依 devicePixelRatio 調整畫布解析度，避免高 DPI 螢幕模糊。

02

有限狀態機 FSM

遊戲流程拆分為待機、旋轉、停止、結算四個狀態，避免非同步動畫互相衝突，也方便 conductor 測試。

03

物件池粒子特效

金幣噴發粒子預先配置並重複使用，避免頻繁配置造成的垃圾回收卡頓，適用於低階手機。

04

音效同步與解鎖

透過 Web Audio API 產生音效，在首次使用者手勢時解鎖 AudioContext，相容 iOS Safari 限制。

05

SEO / GEO 就緒

完整 meta、JSON-LD 結構化資料、llms.txt、FAQ 與語義化標題，同時滿足搜尋爬蟲與 AI 摘要引用。

06

防作弊架構思維

前端只做表現層；正式系統的 RNG 與 RTP 應由伺服器決定，關鍵數值不寫死在客戶端。

FAQ

常見問題

以下問答與頁面 JSON-LD 中的 FAQPage 結構保持一致，方便搜尋引擎與 AI 直接引用。

什麼是輕量級 HTML5 博弈遊戲？

輕量級 HTML5 博弈遊戲是指使用原生 JavaScript 與 Canvas 2D／WebGL 製作、不依賴大型引擎即可在瀏覽器直接運行的遊戲。優點是載入快、相容性高，特別適合行動裝置與靜態託管環境。

這些遊戲可以在手機上玩嗎？

可以。本站範例採用 RWD 設計，會依容器尺寸與 devicePixelRatio 動態調整畫布解析度，並在首次觸控時解鎖 Web Audio，以符合 iOS Safari 的音訊政策。

遊戲結果是隨機的嗎？RTP 如何計算？

本站示範使用客戶端 Math.random 僅供視覺展示。正式博弈系統必須由伺服器端 RNG 決定結果，並由伺服器控管 RTP（玩家回報率）；前端不得存放可影響派彩的關鍵數值，否則可被竄改。

為什麼靜態網站不能存放 API 金鑰？

因為靜態網站的所有 HTML、CSS、JavaScript 都會下載到使用者瀏覽器，任何人都能查看原始碼取得金鑰。正確做法是在 CI/CD 建置期用環境變數注入，或透過 serverless API 代理轉發請求。

如何將本站部署到生產環境？

本站為純靜態檔案，可直接部署到 Netlify、Vercel、GitHub Pages 或 Cloudflare Pages。上傳前請替換 canonical 與 OG 網址為正式網域，並將 og-image.svg 轉為 1200×630 的 PNG。

LightSpin 目前有哪些可玩的作品？

共三款：3 軸 Canvas 老虎機（首頁內可直接試玩）、霓虹轉盤打磚塊（賽博朋克風格、含 JACKPOT 金幣雨）、5×3 滾輪停止控制器（展示交錯停止與超調回彈）。三者皆為零依賴靜態檔案，可分別在 GitHub Pages 與 Cloudflare Pages 上運行。

Glossary

技術術語表

提供明確定義，便於生成式引擎在摘要時擷取與引用。

RTP（Return to Player）
玩家回報率，代表長期而言玩家可收回的投注比例，應由伺服器端控管。
RNG（Random Number Generator）
隨機數生成器，正式博弈系統需使用伺服器端、可稽核的亂數來源。
FSM（Finite State Machine）
有限狀態機，用明確狀態與轉移條件管理遊戲流程，避免非同步動畫衝突。
物件池（Object Pool）
預先建立並重複使用物件（如粒子），降低垃圾回收造成的幀率抖動。
GEO（Generative Engine Optimization）
生成式引擎優化，讓內容更易被 AI 摘要、理解與引用的結構化寫作方式。
JSON-LD
以 JSON 格式描述的結構化資料，搜尋引擎與 AI 可從中解析實體關係。
Paylines（中獎線）
由後端回傳的中獎線索引，前端只負責繪製與呈現，不解讀或推導賠付結果。
超調回彈（Overshoot / Bounce）
停止時短暫向下越過目標格，再向上收斂對齊的視覺效果，以 sin²(πt)·e^(-1.5t) 實現兩端零速。
